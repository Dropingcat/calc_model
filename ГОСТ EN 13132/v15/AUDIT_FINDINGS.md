## 3. Связь с НД (раздел 10 ГОСТ EN 13132, 5725-6, GUM)

- **ГОСТ EN 13132-2012, 10.1/10.2 + Таблица 1**: для каждого диапазона концентраций заданы r и R. Стандартная неопределённость прецизионности по 5725-6/РМГ: `u(σr)=r/2.8` (одно определение) или `u=R/2.8`; при n параллельных — `r/2.8` сохраняется на разность, среднее `u=R/2.8·√(1−1/n)` (рабочая формула для «грубого учёта»).
- **ГОСТ Р ИСО 5725-6-2002, 4.1.4**: `r=2.8σr`, `R=2.8σR`; **5.2.2**: `σR²=σr²+σL²`. → Это и есть модель дисперсии, которую должна оценивать «классическая ANOVA по GUM» + «грубый учёт» по таблицам стандарта.
- **ГОСТ 34100.3-2017, Н.5**: ANOVA (двухуровневый иерархический) как официальный способ оценки составляющих случайных эффектов для суммарной неопределённости — прямо предписанная база для целевого модуля.
- **ГОСТ 34100.3-2017, 5.1.2/5.2.2 (ф.10, 13)**: LPU и коррелированный закон трансформирования — для сквозного бюджета с ковариационными членами со знаком.
- **ГОСТ 34100.3.1-2017, 5.9.6/7.9**: MC с числом испытаний M по требуемой точности (v4 использует N=10⁵) — целевая верификация.
