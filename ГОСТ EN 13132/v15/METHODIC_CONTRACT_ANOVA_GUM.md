## 3. Методическая схема «классическая ANOVA по GUM, грубый учёт» (шаги 1–7)

### Шаг 0. Карта данных v15

- Данные: 6 уровней X (г/г), каждая — 2 инъекции (отклики Y1, Y2), один оператор, один день.
  Источник: v15 `01_Ввод!B7..C12` (mA, mИС) и `D7..H12` (Y1, Y2, X_ном, X_эфф).
- Эффективные X (г/г) = X_ном·pA/pИС, X_ном=mA/mИС. Диапазон X=0,0262…3,1443 г/г. (`01_Ввод!H7..H12`)
- Один день ⇒ классический двухуровневый иерархический ANOVA (Н.5: J дней × K наблюдений) **не воспроизводим**: J=1. Прямое следствие из GUM Н.5.3.3: «методами ANOVA можно оценить в лучшем случае только некоторые составляющие неопределённости».

### Шаг 1. OLS по средним (перенос из v15)

- Модель: Y = a·X + b по средним откликов `Ȳ_i` (усреднение 2 инъекций). Коэффициенты a, b; Sxx, s²(средних откликов), ковариация cov(a,b).
- Доказательство (v15): `03_Статистика!B11` (наклон a), `B12` (b), `B15/B16/B17` (var(a), var(b), cov(a,b)), `B32` (u_reg(X*)). Формулы совпадают с классическим OLS (см. `10_Выбор_Xзв!B22` — «u²_reg = s²·(1/n + (X*−X̄)²/Sxx)»).
- Выход: a, b, V(a,b), u_reg(X) = √(s²·(1/n + (X−X̄)²/Sxx))/|a|.

### Шаг 2. σr — внутриуровневая повторяемость из повторностей инъекций

- Оценка: σr² = MS_pure = SS_pure/df_pure, SS_pure = Σ_i Σ_j (Y_ij−Ȳ_i)², df = Σ_i(n_i−1) = N−m.
- Для 6×2: df_pure = 6·(2−1)=6, N=12.
- Доказательство (v15): `03_Статистика!B22` (SS pure error), `B23` (df PE) — формула SS_PE=Σ n_i·s²_i из `01_Ввод!O7..O18`; `B28` (проверка равенства повторов).
- Статус в «грубом учёте»: σr используется ТОЛЬКО как компонента разложения σR (см. шаг 3/4) и НЕ входит отдельной строкой в суммарный бюджет, чтобы не задвоить повторяемость, уже усреднённую в OLS-дисперсии (анти-двойной счёт, разд. 6).

### Шаг 3. σR, σL — из табл.1/2 ГОСТ EN 13132 (межлабораторная воспроизводимость)

- Прецизионность табл.1/2 — это межлабораторные r и R на уровне вероятности 95 % (ГОСТ EN 13132 §10.1). По ГОСТ Р ИСО 5725-6 §4.1.4:
  - σr_табл = r/2,8
  - σR_табл = R/2,8
  - σL_табл = √(max(0, σR² − σr²)) — межлабораторная составляющая
- Dialogic choice (а): внутриуровневая σr из данных v15 (шаг 2) может быть подставлена вместо σr_табл для согласования шкалы: σL = √(max(0, σR_табл² − σr_данные²)) (используется если оценки сопоставимы по единицам, обе в % мас. после пересчёта; при малом df=6 надёжность ниже — см. границы применимости разд. 7).
- Статус: σL из табл.1/2 — **нормативно оправданный «грубый учёт»** в отсутствие межлабораторных данных калибровки лаборатории. Обоснование: 5725-6 §7 (использование значений точности метода при оценивании неопределённости), 17025 §7.6.3 прим.1, РМГ 61 §5.5 (разбиение диапазона на поддиапазоны постоянства σR).

### Шаг 4. u_repr — вклад воспроизводимости табл.1/2 в суммарный бюджет

- Для **единичного результата** 1 определения: u_repr = σR_табл = R(X)/2,8.
- Для **результата как среднего из 2 определений** (ГОСТ EN 13132 требует сходимость «двух результатов» §10.1; протоколь практека — 2 параллельных с |x1−x2|≤r): u_repr(mean_2) = σR·√(1−σr²/σR²·(1−1/2)) = √(σR² − σr²/2) = √(R²−r²/2)/2,8.
  Доказательство: 5725-6 §4.2.3 (CD=√(R²−r²/2) для среднего из 2) — то же выражение для стандартной неопределённости среднего при межлабораторной составляющей.
- Численный пример для поддиапазона (1,0;3,0]: r=0,1; R=0,3:
  - u_repr(1 определение) = 0,3/2,8 = **0,1071 % мас.**
  - u_repr(среднее из 2) = √(0,3²−0,1²/2)/2,8 = 0,2916/2,8 = **0,1041 % мас.** (≈ −3%).
- **Делитель 2,8** (не 2,77): ГОСТ EN 13132 §10.1 определяет r/R как 95%-ные пределы по стандартной трактовке 5725-6 §4.1.2/4.1.4 («2,8 вместо f√2=2,77»). РМГ 61 §5.2.1.5 (2,77) относится к параметру Q(0.95,n) методики с n параллельными, РМГ 76 §5.13.4 (Rл=2,77) — к **внутрилабораторной** прецизионности; к межлабораторным r/R ГОСТ EN 13132 применять **2,8**. (Расхождение делителей зафиксировано — TD-DEV-192.)
- Привязка к X-шкале: r, R по табл.1 задаются в % мас. Результат пробы в % мас. переводится в X(г/г) через коэффициент (см. разд. 9, U3): u_repr(X) = u_repr(% мас.)·(m_ИС·p_ИС/m_пробы)·0,01 в зависимости от выбранной формы результата.

### Шаг 5. Суммарный бюджет u_c = √(Σ u_i²) с анти-двойным счётом

Канонический состав (см. разд. 5, Q12; R6):

```
u_c² = u_модель² + u_эталоны² + u_чистота² + u_весы² + u_проба² + u_repr²
```

С анти-двойным счётом (разд. 6): u_модель включает усреднённую повторяемость инъекций; u_repr = √(σR²−σr_лок²/2) (для среднего из 2) или R/2,8 (для единичного) — НЕ дублирует внутриуровневую повторяемость; если σr локальная оценена и сопоставима, она исключается из u_repr.

### Шаг 6. U = k·u_c, k по ν_eff (Welch–Satterthwaite) или k=2

- Правило: по умолчанию **GUM-строгий путь** — ν_eff по формуле (G.2b), k=t_{0,975}(ν_eff). k=2 (РМГ 61 §6.5.2) — частный случай при ν_eff ≥ ~30 (G.6, 6.3.3).
- В v4 реализовано именно так: `Неопределенность!B10` = df_модели (OLS: n−2=4), `B11` = ν_eff Welch–Satterthwaite, `B12` = TINV(1−P; ROUND(ν_eff)), `B13` = U=k·u_c. (см. разд. 8.)
- Для v16: ν_i для табличной σR — ∞ (тип B; оценка установлена из большого межлабораторного эксперимента). При доминировании вклада прецизионности табл.1/2 (ν=∞ по умолчанию — альтернатива упрощённой схеме РМГ 61 §6.5.2) k≈1,96 (ν_eff≈1,8·10³). При малых ν_eff k растёт по Стьюденту (например, k=t₀,₉₇₅(6)=2,447 при ν_eff=6). Утверждение «k заметно >2» некорректно: оно верно только в гипотетическом случае доминирования малых степеней свободы регрессии (df=4) без вклада u_repr.
- В протоколе указывать: k, ν_eff, уровень доверия 95 %.

### Шаг 7. Профиль U(x) по диапазону

- Профиль: U(x) = k(ν_eff(x))·u_c(x), x на сетке из 200 точек (диапазон X калибровки, шаг (max−min)/199, как v4 `Профиль U(x)!B2`).
- Обязательные колонки: x | u²(x) модель | u(x) модель | u_c(x) с эталонами | U(x)=k·u_c | маркер x_pred.
  (Эталон v4 `Профиль U(x)!A3..G3`; v15 `05_Профиль` — только u_c, без k, без эталонов, 61 точка; это разница C4/TD-DEV-24.)
- Результат пробы x_pred — маркер на профиле; итог — «x_pred ± U(x_pred)» c k(x_pred), ν_eff(x_pred).

## 6. Анти-двойной счёт — явные правила исключений (Q3, R3)

Проблема (Q3, M5): остаточная дисперсия OLS по средним (≈21% в «06_Отчёт» v15) уже содержит внутриуровневую повторяемость инъекций. Добавление u_repr=R/2,8 целиком как независимого вклада частично задваивает этот вклад.

Формализованное правило (выбор — см. также документируемые допущения):

**Правило 1 (разделение масштабов).** u_модель — это неопределённость *построения калибровочной прямой* (локальная, внутрилабораторная, в X-единицах). u_repr (табл.1/2) — это *воспроизводимость метода между лабораториями* для результата анализа. Это две РАЗНЫЕ понятийные плоскости; их можно суммировать. НО внутри одновременного использования не допускается дважды учитывать одну и ту же повторяемость инъекций.

**Правило 2 (не дублировать σr).** u_модель включает σr (усреднённую по n_i). Значит σr из шага 2 НЕ добавляется отдельной строкой в бюджет. σr из шага 2 используется ТОЛЬКО для разложения σL (σL=√(σR²−σr²)) и для формы u_repr(среднего из n).

**Правило 3 (форма u_repr с вычитанием локальной повторяемости).** Для результата как среднего из n=2 параллельных определений лаборатории:
```
u_repr² = σR² − σr²·(1 − 1/n) = R²/2,8² − r²/2,8² · (1 − 1/2)   [n=2]
        = (R² − r²/2)/2,8²
```
Это **минимально самосогласованная** форма: межлабораторный вклад σL=√(σR²−σr²) + внутрилабораторная повторяемость среднего σr/√n. Нижняя граница совпадает с CD=√(R²−r²/2) из 5725-6 §4.2.3 (для сличений с опорным/средним из 2).

**Правило 4 (проба vs u_repr).** Если u(Y0) пробы оценивается из фактических повторных инъекций пробы и результат пробы — среднее из p, то повторяемость пробы σr_проба/√p **вычитается** из внутрилабораторной повторяемости σr_метод/√n в формуле u_repr: u_repr²(среднего пробы) = σR² − σr_метод²·(1−1/n) [где σr_метод — повторяемость метода по табл. 1: r/2,8]. Если статистически результат пробы получен в тех же условиях повторяемости, что и табл.1 (σr_проба ≈ σr_метод), то u(Y0) фактически является реализацией σr/√p, и двойного счёта нет ТОЛЬКО если |u(Y0)|² ≤ |σr_метод|²/√n/2… — на практике: использовать либо (а) u_проба из заводских повторных инъекций и u_repr=R/2,8 (единичный результат), либо (б) среднее из 2 по ГОСТ EN 13132 с u_repr=√(R²−r²/2)/2,8 и НЕ добавлять u(Y0) отдельно — как протокольная форма по ГОСТ EN 13132. Рекомендуется (б).

**Правило 5 (LoF не входит).** F-тест lack-of-fit (v15 `03_Статистика!B26/B29`) — критерий адекватности ЛИНИИ, не вклад неопределённости. При «LoF не выявлена» — не добавлять «погрешность линейности» в бюджет (задвоение с s²_остаточная). При «LoF неадекватность» — модель не утверждается (BLOCK), контракт не применяется.

**Правило 6 (эталоны и чистота).** u_эталоны и u_чистота — независимые входы (паспорт чистоты ≠ сертификат эталона). При использовании ОДНОГО маточника для всех уровней — корреляционная матрица X (v15 `04_Ковариация`), а не покомпонентное суммирование. Не суммировать u_эталоны с чистотой при полной корреляции ρ=1.

Итоговая формула для v16 (протокольная форма «среднее из 2», отсутствие пробы на этапе градуировки):
```
u_c²(X0) = u_модель²(X0) + u_эталоны²(X0) + u_чистота²(X0) + u_весы²(X0) + (R²−r²/2)/2,8²
```

> **Уточнение R-05 (итерация 3, блок `gost13132-v16-xlsx-profile-uc`, P1):** профиль U(x) книги v16 использует **smooth-аппроксимацию как рекомендуемую** — непрерывную кусочно-линейную интерполяцию r(w), R(w) по границам табл.1 (узлы по правилу R-05: на границе — значение более высокого диапазона; верхняя граница шкалы — последнего диапазона); `u_repr(mean2) = √(R(w)² − r(w)²/2)/2,8`. Причины: устранение ступенчатых скачков профиля U(x) (нефизичное поведение на границе поддиапазонов), непрерывность результата пробы при w0 вблизи границы табл.1 (TD-DEV-206), согласованность U(06_Итог) с маркером x_pred на профиле. **step остаётся консервативной альтернативой** (режим по умолчанию ядра `anova_gum.py`, РМГ 61 §5.5 — поддиапазоны постоянства σR; применяется там, где важна намеренная осторожность). Оба режима реализованы в `u_repr_from_tables(..., interpolation="step"|"smooth")`; книга собирается в режиме `"smooth"` (режим указан в шапке листа 04_Профиль U(X)).

Это **в 4–5 раз больше** u_модель v15 (≈0,0093) — подтверждает, что «прецизионность табл.1» — доминирующий вклад (TD-DEV-29, M5).

## 11. Ключевые методические решения (R1–R6) — финальная редакция

- **R1 (делитель r/R → u_repr):** Делитель **2,8** (5725-6 §4.1.2/4.1.4; ГОСТ EN 13132 §10.1 трактует r/R как 95%-ные пределы). Для протокольной формы «среднее из 2»: `u_repr = √(R²−r²/2)/2,8` (5725-6 §4.2.3). Для единичного результата: `u_repr = R/2,8`. Примечание: в PLAN_FACTORY_CYCLE.md §3 тест «б» указан `u_repr≈0.0357` — это **r/2,8**, а не R/2,8 (0,3/2,8=0,1071); тест плана содержит ошибку (TD-DEV-193), аналитик уже отметил (0,1071) — в v16-тест использовать 0,1071/0,1041.
- **R2 (ANOVA-компоненты из 6×2):** σr — из повторностей инъекций (df=6); σL — из табл.R (σL=√(max(0,σR²−σr²))); σR — из табл.1/2; иерархическая модель GUM H.5 в полном виде (J дней) НЕ реализуема на однодневных данных — вместо неё комбинированный «ANOVA (внутренний σr) + табл. σR».
- **R3 (анти-двойной счёт):** OLS-остаток (≈21% дисперсии) = локальная повторяемость + компоненты линии; в бюджет не включается σr отдельно; u_repr входит как √(R²−r²/2)/2,8 без задвоения локальной повторяемости; LoF/Recovery/объём/неоднородность исключены. Формула: `u_c² = u_модель² + u_эталоны² + u_чистота² + u_весы² + u_repr²` (для результата пробы + u_проба² с правилом вычитания).
- **R4 (профиль):** Профиль — **U(x)=k·u_c(x)** (как v4), 200 точек, маркер x_pred; НЕ u_c как в v15.
- **R5 (ν_eff):** По Welch–Satterthwaite (GUM G.2b): ν_eff = u_c⁴ / Σ(u_i⁴/ν_i). Степени свободы: регрессия ν=n−2=4; повторности пробы ν=p−1; повторности уровней ν=Σ(n_i−1)=6 (через s²_модель); табл.1/2 — ν=∞ (тип B). k=t_{0,975}(ν_eff), при ν_eff≥30 → k≈2.
- **R6 (состав сквозного бюджета):** 5+1 вкладов: модель, эталоны, чистота, весы, проба (для результата), прецизионность табл.1/2; исключения — см. разд. 5/6.
