### фракционка ГОСТ_2177.xlsx (ФР-13 — потери по таблице 4 ГОСТ 2177-99)

| Дефект | Ячейка | Было | Стало |
|---|---|---|---|
| ФР-13 | `Лист1!H28` (V_K) | `=(F26/G26)+0.5` (ISO: `Lc=0,5+(L−0,5)/(1+(101,3−p)/8)`) | `=IF(A1≤Табл4!B3, C3, IF(A1≥Табл4!B23, C23, INDEX/MATCH кусочная интерполяция A))*C28 + (…та же для B)` |
| ФР-13 | новый лист `Табл4` | — | Таблица 4 ГОСТ 2177-99: кПа, мм рт.ст. (560..760), A, B — 21 строка (B3:B23, C3:C23, D3:D23) |
| ФР-13 | `Лист1!H29` | `=C26+(C28-H28)` | не изменялась (пересчитается автоматически) |
| ФР-13 | `Лист1!K28/K29` | `MROUND(ROUNDUP(H28/H29,1),0.5)` | не изменялись (пересчитаются) |

**Формула H28** (V_K = A·L + B, L=C28 — потери):
```
=IF(A1<=Табл4!$B$3,Табл4!$C$3,
   IF(A1>=Табл4!$B$23,Табл4!$C$23,
      INDEX(Табл4!$C$3:$C$23,MATCH(A1,Табл4!$B$3:$B$23,1))
      +(INDEX(Табл4!$C$4:$C$24,MATCH(A1,Табл4!$B$3:$B$23,1))
        -INDEX(Табл4!$C$3:$C$23,MATCH(A1,Табл4!$B$3:$B$23,1)))
       *(A1-INDEX(Табл4!$B$3:$B$23,MATCH(A1,Табл4!$B$3:$B$23,1)))
       /(INDEX(Табл4!$B$4:$B$24,MATCH(A1,Табл4!$B$3:$B$23,1))
         -INDEX(Табл4!$B$3:$B$23,MATCH(A1,Табл4!$B$3:$B$23,1)))))*C28
  + <та же структура для B (колонка D)>
```
Кусочная линейная интерполяция A/B по давлению A1 (мм рт.ст., из `Ввод данных!D3`). Проверено эмуляцией:
- **P=760** (A=1, B=0) → V_K = L (напр. L=0.5 → 0.5 ✓)
- **L=2.5, P=740** (A=0.750, B=0.125) → V_K = **2.0** ✓ (пример ГОСТ 2177-99)
- P=700, L=1.0 → 0.75; P=725 (между узлами) → A=0.6335, B=0.183 (интерполяция)
- За пределами 560..760 — экстраполяция крайними значениями (защита `IF`).

Примечание: `FORECAST` (линейная регрессия) отклонён — на P=740 даёт V_K=1.91 вместо 2.0 (таблица 4 нелинейна); используется точная кусочная интерполяция.
