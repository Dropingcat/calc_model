# TD-D86-002 / TD-D86-006 — процедурный контроль Table 5 и GUM-модель ASTM D86

## Статус
Кодовый слой + book-слой реализованы (fraction_lib v3.13, коммит этой ветки).
**Открытый остаток:** справочник Table 5 сведён по типовой структуре D86-23 и
ДО ВВОДА В ЭКСПЛУАТАЦИЮ обязан быть сверен с лицензионной копией ASTM D86-23
ответственным метрологом (запись в листе «Реестр_НД» + подпись в SOP).

## TD-D86-002: контроль условий Table 5 (`fraction_lib/d86_procedure.py`)
Архитектура повторяет procedure.py (ГОСТ, TD-2177-006): нормативный «шлюз»
между журналом наблюдения и calculate(); математическое ядро не затронуто.

Классы несоответствий:
* INVALID → флаг `TABLE5_INVALID:<ID>` (verdict FAIL; результат не репортится);
* MISSING (незаполненный пункт) → тоже FAIL — нельзя принимать решение по
  недокументированным условиям;
* WARNING → CONDITIONAL, решение метролога.

Проверяемые величины (константы `D86_TABLE5_*` в constants.py):
| ID | Требование | Класс |
|---|---|---|
| SAMPLE_VOL | объём пробы 99.5–100.5 мл (все группы) | INVALID |
| CONDENSE_RATE | гр.1–3: 4–5 мл/мин; гр.4: >0 и ≤5 | INVALID |
| IBP_TO_5 | ≤10 мин для гр.1–2 (для 3–4 лимит НД не задан → не проверяется) | INVALID |
| TIME_TO_IBP | ориентир ≤10 мин (гр.1–2) | WARNING |
| BATH_PREHEAT / APPARATUS | подтверждение оператора | INVALID |

Book-слой: лист **«Условия_Table5»** в ASTM-книге v3.13 — справочник + вердикт
по эталонным данным листа «Ввод» (группа и объём подтягиваются из книги;
остальные поля — MISSING до добавления колонок журнала в «Ввод», это честно
отражено в вердикте и является остатком TD-D86-003/004).

## TD-D86-006: GUM-модель (`uncertainty.evaluate_gum_d86`)
Модель Y = T_c(V) = T_obs + C_p + ΔT_loss, отчёт округлён до 0.5 °C.

Бюджет (полуширины — константы `D86_U_*`, прямоугольные; u1 — тип A при s_rep):
| Код | Компонент | c_i |
|---|---|---|
| u1 | наблюдение T_obs | 1 |
| u2 | давление P (Янг) | −0.00012·(273+t_bar) °C/мм |
| u3 | t_bar | 0.00012·(760−P) |
| u4 | мениск/выступающий столбик (экспертно ±0.5) | 1 |
| u5 | отсчёт объёма ±0.5 мл через локальный slope | \|slope\|·100/V_колбы |
| u6 | коррекция потерь ΔT_loss (экспертно ±0.5) | 1 |
| u7 | округление отчёта 0.5 °C | 1 (±0.25) |

Welch–Satterthwaite, k_eff = max(k, t95) — как в ГОСТ-модели.
Флаги вне канона (`LOSS_CORR_UNSTABLE`, `TABLE5_INVALID:*`, `INVALID_TEST`)
→ valid_for_reporting=False.

Book-слой: лист **«GUM_u(T)»** в ASTM-книге v3.13 (генерируется тем же
прогоном, что и ГОСТ-лист; golden-тест сверяет строки листа с
`evaluate_gum_d86().as_dict()` без допусков).

## Экспертные оценки, требующие подтверждения лабораторией
u4, u6 (±0.5 °C), u2 (±0.5 мм рт.ст.), граничные условия Table 5 для гр.3–4.
Эти числа меняются ТОЛЬКО через constants.py + перерегенерацию книг
(`python -m fraction_lib.excel_generator`) + pytest.
