# TD-2177-003 — Валидация цифровой номограммы ГОСТ 2177-99 (рис. 6)

**Статус:** ЧАСТИЧНО ЗАКРЫТО (2026-10-08): независимая структурная валидация реализована,
обнаружен и задокументирован дефект оцифровки; окончательное закрытие требует сверки
с бумажным оригиналом рис. 6 (нужен скан/копия НД).

## Что сделано
1. **KT-1 (self-consistency узлов)**: `_nomogram_values` в 51 узле сетки возвращает ровно
   табличные значения — PASS (dev = 0).
2. **KT-2 (линейность между узлами)**: midpoint-проверка по всем соседним парам — PASS
   (dev ≤ 9e-16). Подтверждает: интерполяция линейна, как заявлено.
3. **KT-3 (монотонность)**: r/R должны быть невозрастающими по крутизне S.
   **ОБНАРУЖЕН ДЕФЕКТ**: серии `r_з` и `R_з` имеют скачок ВВЕРХ на S=1.3→1.4
   (r_з: 2.3→2.7; R_з: 5.1→6.0). Остальные 4 серии (r_нк, r_кон, R_нк, R_кон) монотонны.
   Физически точность повторяемости/воспроизводимости не может расти с крутизной кривой —
   вероятна ошибка оцифровки двух узлов. Тест фиксирует дефект через whitelist известных
   нарушений: новые нарушения сделают тест красным; после исправления whitelist обнуляется.
4. **KT-4 (полнота сетки)**: покрытие [0.0, 5.0] шагом 0.1, 51 узел — PASS.
5. **Устранена скрытая деградация**: выход за диапазон (S > 5.0) раньше молча возвращал
   крайнее значение S=5.0 (занижение r/R → риск ложной приёмки по повторяемости).
   Теперь выставляется флаг `NOMOGRAM_CLAMPED_HIGH` (паттерн «мягкий режим обязан оставить
   след», как PRESSURE_CLAMPED / EXTRAPOLATED_96_98). Дубли функций в gost2177.py
   переданы в общий out-param `self._nomogram_flags`, базовый пайплайн подмешивает их в flags.

## Что осталось (критерии полного закрытия)
- Сверить узлы r_з/R_з при S∈[1.2..1.5] с бумажной номограммой рис. 6 ГОСТ 2177-99
  (или ISO 3405 рис. — эквивалентна); исправить constants.GOST2177_NOMOGRAM; обнулить whitelist KT-3.
- Добавить 2–3 эталонные контрольные точки «крутизна → r,R» из авторитетного источника
  (справочник/публикация) в test_normative (см. также пункт PROGRESS 6).
- Синхронизировать книгу v3.13 (лист Номограмма) с исправленной сеткой — часть TD-2177-001.

## Контракт API
- `_nomogram_values(slope: float, flags: list[str] | None = None)` — обратная совместимость сохранена.
- Новый флаг результата: `NOMOGRAM_CLAMPED_HIGH` (в FractionResult.Flags).
