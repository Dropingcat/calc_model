# TD-2177-002 — Политика коэффициентов A, B Таблицы 4 для нетабличного давления (ГОСТ 2177-99)

**Статус:** политика формализована в `fraction_lib` (код + тесты + документ). Закрепление в SOP лаборатории — внешний шаг, остаётся открытым.
**Реализация:** `GOST2177Calculator(table4_policy=...)`, константы `GOST2177_TABLE4_POLICY_MODES/DEFAULT` (`fraction_lib/constants.py`), флаг `PRESSURE_CLAMPED`.
**Книга v3.12:** контроль `560 ≤ P ≤ 760` в листах Табл4/Расчёт (J/K молчат вне диапазона) — соответствует канону `strict`.

## Нормативная рамка

Таблица 4 ГОСТ 2177-99 задаёт A, B только для дискретных давлений **560…760 мм рт. ст.**
(шаг 10). Стандарт НЕ содержит явной инструкции «линейно интерполировать между строками» —
это алгоритмическое решение реализатора, поэтому оно должно быть формально закреплено,
а не молча зашито в формулу MATCH.

## Принятая политика (три уровня)

| Ситуация | Режим strict (канон, по умолчанию) | Режим clamp_low (экспериментальный) |
|---|---|---|
| 560 ≤ P ≤ 760, табличное | строка таблицы | то же |
| 560 < P < 760, нетабличное | линейная интерполяция между соседними строками | то же |
| P < 560 | `PressureOutOfRangeError` | A,B строки 560 + **флаг `PRESSURE_CLAMPED`** |
| P > 760 | `PressureOutOfRangeError` | `PressureOutOfRangeError` (запрещён всегда) |

### Обоснование линейной интерполяции внутри диапазона

Строки таблицы 4 — дискретизация непрерывной зависимости (номограмма рис. 6 / гладкая
функция A(P), B(P)); при шаге 10 мм рт. ст. линейная интерполяция между соседями даёт
погрешность много меньше цены деления барометра (0,1 кПа ≈ 0,75 мм рт. ст.). Решение
фиксируется здесь как нормативно-технический компромисс и подлежит включению в SOP.

### Почему clamp_high (>760) сознательно отсутствует

На границе 760 мм рт. ст. A = 1.000, B = 0.000 (потери не корректируются). За ней
экстраполяция давала бы A > 1, B < 0 — физически бессмысленное усиление потерь с
отрицательной константой. Давление выше 760 в контексте метода — это либо ошибка ввода
(sea-level corrected pressure вместо местного — прямой запрет D86/аналогов), либо
штормовое значение, требующее перераспределения испытаний по НД. Молчаливый clamp сюда
маскировал бы ошибку данных, поэтому выбран безусловный отказ.

### Условия применения clamp_low

- Только по письменному решению в SOP/методике лаборатории (вне прямых требований НД).
- Результат обязан отображаться с флагом `PRESSURE_CLAMPED` во всех слоях (книга/отчёт/GUI).
- Не совместим с аккредитацией по чистому ГОСТ 2177 без регистрации отклонения.

## Контракт API

```python
calc = GOST2177Calculator()                          # strict — канон НД
calc = GOST2177Calculator(table4_policy="clamp_low") # экспериментальный режим
res = calc.calculate(inp)   # P=500 → res.Flags включает "PRESSURE_CLAMPED"
                            # P=800 → PressureOutOfRangeError в любом режиме
GOST2177Calculator(table4_policy="clamp_high")       # ValueError (недопустимый режим)
```

## Тесты (`test_gost2177.py::TestTable4PolicyTD2177002`, 6 шт.)

default=strict; неизвестный режим → ValueError; strict P=500 → ошибка;
clamp_low P=500 → Vk = 0.231·L+0.384 и флаг; clamp_low внутри диапазона → флага нет;
clamp_low P=800 → ошибка. Прогон: **203 passed**.

## Что осталось открытым

- **SOP:** включить текст политики (интерполяция внутри, strict/clamp_low снаружи, запрет >760)
  в процедурный документ лаборатории — это буквально критерий закрытия TD-2177-002.
- **TD-2177-001:** книга Excel умеет только strict; выбор режима через генератор — при синхронизации.
