# TD-2177-007 — GUM uncertainty model для ГОСТ 2177 (методы А и Б)

**Статус:** закрыто в `fraction_lib/uncertainty.py` (2026-10-08). Тесты: `fraction_lib/tests/test_uncertainty_td2177007.py` (15 шт.), численная валидация чувствительностей центральными разностями.

## Модель величины
Y = T_corr(V) = MROUND(T_obs + ΔT_p(p, t_bar) + ΔT_m(S), 0.5), где ΔT_p — нормативная поправка на давление (kPa-форма 0.0009·(101.3−p)·(273+t)), ΔT_m — цифровая номограмма (рис. 6, оцифровка валидирована KT-1..KT-4 в TD-2177-003).

## Бюджет (полуширины → стандартные неопределённости)
| Код | Компонент | Тип | Закон | Полуширина | Чувствительность |
|---|---|---|---|---|---|
| u1 | Наблюдение T_obs | A/B | прямоугольный или s_rep/√n | 0.5 °C (или из повторностей) | 1.0 |
| u2 | Барометрическое давление p | B | прямоугольный | 0.5 кПа (п.4.3) | c_p = −0.0009·(273+t_bar) °C/кПа |
| u3 | Температура барометра t_bar | B | прямоугольный | 0.5 °C | c_t = 0.0009·(101.3−p) °C/°C |
| u4 | Поправка выступающей нити | B | прямоугольный | 0.2 °C (экспертно) | c_t |
| u5 | Остаток оцифровки номограммы | B | прямоугольный | 0.3 °C (консервативно: дефект узлов S=1.3–1.4) | 1.0 |
| u6 | Дискретизация MROUND 0.5 | B | прямоугольный | 0.25 °C | 1.0 |

u_c = √Σ(c_i·u_i)²; U = k·u_c. **k повышен с 2 по Уэлч–Саттертуэйту**, если задан тип A при малом n (ν_eff мал → t95 > 2). При только B-компонентах ν_eff→∞, k=2 остаётся.

## Связь с политикой fraction_lib (замкнутость цикла TD-2177-002/003/004)
- флаг `EXTRAPOLATED_96_98` → штраф u1 ×2.0 (`EXTRAPOLATION_U_FACTOR`, экспертно);
- флаги `PRESSURE_CLAMPED` / `NOMOGRAM_CLAMPED_HIGH` → `valid_for_reporting=False` + note: результат во внедиапазонном режиме, отчёт только с обоснованием.

## Обоснование экспертных оценок
- u4=0.2 °C: поправка на выступающий столбик ртути в НД не нормируется по точности; взята половина цены деления типовой поправки. Переключается (`include_thread_correction`).
- u5=0.3 °C: верхняя граница расхождения оцифровки в узлах S=1.3–1.4 (документировано в TD-2177-003); после переработки карты можно снизить до 0.1 °C.
- Штраф ×2 за экстраполяцию: эвристика уровня «вне интервальной области интерполяции»; подлежит калибровке по межлабораторным данным (остаточный долг — эмпирическая валидация покрытия, см. ниже).

## Ограничения и остаточный долг
1. Компоненты считаются независимыми (ковариации t_bar↔p пренебрежимо малы — разные приборы).
2. Вклад скорости конденсации/парового равновесия (процедурные эффекты) в модель не входит — покрыт checklist TD-2177-006 как бинарный контроль, а не как количественный вклад.
3. Требуется эмпирическая проверка покрытия 95% на CRM/МСО (способ 3 тройной валидации) — вынесено в TD-D86-006-подраздел / общий слой GUM для D86.
